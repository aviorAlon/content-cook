# 长单镜视频提示词的写法（P1–P3）

"一条提示词出一整段 15 到 30 秒、中间不剪的视频"（Seedance / Veo 一类长单镜模型）和我们短剧产线的"4–10 秒逐镜 + 账本 + QC + 后期拼接"是两种生成方式。
这份文档整理前一种写法里值得借用的判据，编号 P1–P3 在代码注释、测试和其它文档里引用；单条视频模块（`docs/clip-spec.md`）整套采用这里的三段式，
短剧产线只取判据、不取结构。

## 三段式

| 段 | 写什么 |
|---|---|
| 【全片设定】 | 全片不变的东西，只写一次。画面：一句带材质词的风格锚句、色板（5–7 个具体色名）、光线；构图：画幅与主体位置；另写时长与分辨率、文字政策（有没有字、放在哪）、声音说明 |
| 【分段时间线】 | 绝对时间段（可以带小数：0–2.5 秒、2.5–6 秒），一段一行，每行 = 景别 + 画面 + 声音 + 要出现在画面里的文字；一段只做一件事；最后一段写清最后一帧停在什么上 |
| 【衔接与收尾】 | 一镜到底还是允许硬切；换景怎么过渡；最后一帧停在什么上；不许出现的东西 |

段与段之间不能互相矛盾：画幅只在【全片设定】写一次，【分段时间线】里不再提；文字政策说"全片无文字"，时间线里就不能出现画面文字。

## 三条判据

| 编号 | 判据 | 为什么 | 我们的落地 | 位置 |
|---|---|---|---|---|
| P1 | 画幅写明并排除另一种画幅；主体放在画面哪一块写成事实 | 只写"9:16"时模型仍会按横构图摆主体，再裁成竖幅；把另一种画幅明确排除、把主体位置写成事实，构图才稳 | 形态卡的 `composition` 句（中英）随运动预算句进视频提示词：先写主体落在画面哪一块，句末写明是原生画幅、不是另一种画幅裁出来或拉宽的；单条视频模块的【全片设定】由编译器按画幅自动补画幅与排除句 | `form_cards.json`、`storyvideo.forms`、`clip.prompts` |
| P2 | 色板写 5–7 个具体色名（雾蓝、砖红、铜金），不写"电影感配色""高级灰" | 空话不给模型任何可执行的信息；具体色名跨镜稳定，也方便人检查成片 | 五张新风格骨架的「调色/光线」项要求具体色名，起草时进系统提示词；出图风格卡与单条视频的色板少于 5 个色名时给提示 | `style_library.json`、`imagecraft.lint`、`clip.lint` |
| P3 | 与参考图的相似度写成百分比（例如"相似度约 80%"） | "像参考图"没有程度；百分比让模型知道哪些可以变（姿势、光线）、哪些要守住（脸） | `shot.reference_roles[].fidelity`（1–100）→ 首帧提示词里的相似度说明；镜头页参考图用途行加「相似度 %」 | `storyvideo.spec`、`storyvideo.prompts.reference_roles_clause` |

三条都只在写了对应字段的项目上生效，老项目的提示词一个字不变（提示词金丝雀守着）。

短剧产线已经有、不用再做的：时间块带时码和声音（`beats[{t, picture, performance, sound}]`）、最后一帧停在什么上（出口状态）、画面文字政策与遮挡区、
否定清单（`neg` / `neg_extra`）、说话时压低配乐（配乐层 `duck`）、动作顺序（beats 有序）。
